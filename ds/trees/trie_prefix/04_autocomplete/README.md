# Задача 4. Автодополнение по префиксу

## Задача

Реализовать операцию `Autocomplete(prefix)`.
Она должна вернуть все слова дерева, которые начинаются с указанного префикса, в алфавитном порядке.

Если слов с таким префиксом нет, вернуть пустой результат.

## Идея

Сначала найдём узел, где заканчивается префикс.
Все слова с этим префиксом находятся в поддереве этого узла.
Остаётся обойти поддерево в глубину и собрать все отмеченные концы слов.
Чтобы результат был предсказуемым, отсортируем найденные слова.

## Как работает

1. Идём по символам префикса от корня.
2. Если перехода нет, возвращаем пустой результат.
3. Запоминаем узел, в котором закончился префикс.
4. Запускаем обход в глубину из этого узла.
5. Если узел отмечен как конец слова, добавляем текущую строку в результат.
6. Для каждого ребёнка продолжаем обход с новой строкой.
7. Сортируем результат и возвращаем его.

## Пример

Добавим слова `app`, `apple`, `apply`, `ape`, `bat`.

```text
Autocomplete("app")  -> [app apple apply]
Autocomplete("appl") -> [apple apply]
Autocomplete("ap")   -> [ape app apple apply]
Autocomplete("b")    -> [bat]
Autocomplete("z")    -> []
Autocomplete("")     -> [ape app apple apply bat]
```

Обратите внимание на `Autocomplete("ap")`: слово `ape` стоит раньше `app`, потому что при сравнении строк `e` меньше `p`.

## Сложность

- Поиск узла префикса: O(P), где P - длина префикса.
- Обход поддерева: O(V), где V - количество просмотренных узлов.
- Сортировка результата: O(K log K), где K - количество найденных слов.
- Итоговое время: O(P + V + K log K).
- Память: O(K * L) для хранения результата, где L - средняя длина слова.
