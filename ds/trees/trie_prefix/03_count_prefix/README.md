# Задача 3. Сколько слов начинается с префикса

## Задача

Реализовать операцию `CountWordsWithPrefix(prefix)`.
Она должна возвращать количество слов в дереве, которые начинаются с указанного префикса.

Повторная вставка одного и того же слова не должна увеличивать счётчик.
Например, если дважды добавить `app`, слово всё равно считается один раз.

## Идея

В каждом узле будем хранить поле `prefixCount`.
Оно означает, сколько слов проходит через этот узел.
Когда добавляется новое слово, увеличиваем `prefixCount` у всех узлов на его пути.
Тогда для любого префикса ответ уже лежит в узле, где заканчивается этот префикс.

## Как работает

### Вставка

1. Идём по символам слова и создаём недостающие узлы.
2. Запоминаем все узлы на пути в срезе `path`.
3. Если последний узел уже отмечен как конец слова, слово повторяется и ничего не меняем.
4. Иначе ставим `isEnd = true`.
5. Увеличиваем `prefixCount` у каждого узла из `path`.

### Подсчёт

1. Идём по символам префикса.
2. Если какого-то перехода нет, возвращаем `0`.
3. Если прошли весь префикс, возвращаем `prefixCount` текущего узла.

## Пример

Добавим слова `app`, `apple`, `apply`, `ape`, `bat`.

```text
root
|- a
|  `- p             (4 слова: app, apple, apply, ape)
|     |- p          (3 слова: app, apple, apply)
|     |  `- l       (2 слова: apple, apply)
|     `- e          (1 слово: ape)
`- b
   `- a
      `- t          (1 слово: bat)
```

Результаты:

```text
CountWordsWithPrefix("app")  -> 3  (app, apple, apply)
CountWordsWithPrefix("appl") -> 2  (apple, apply)
CountWordsWithPrefix("ap")   -> 4  (app, apple, apply, ape)
CountWordsWithPrefix("b")    -> 1  (bat)
CountWordsWithPrefix("")     -> 5  (все слова)
CountWordsWithPrefix("z")    -> 0  (такого префикса нет)
```

## Сложность

- `Insert`: время O(L), память O(L) на путь в срезе `path`.
- `CountWordsWithPrefix`: время O(P), где P - длина префикса.
- Дополнительная память при подсчёте O(1).
