# Задача 2. Поиск по префиксу

## Задача

Реализовать операцию `StartsWith(prefix)`.
Она должна отвечать, есть ли в дереве хотя бы одно слово, которое начинается с указанного префикса.

В отличие от `Search`, здесь не нужно проверять, что префикс является целым словом.
Достаточно проверить, что путь по символам префикса существует.

## Идея

Любое слово, начинающееся с префикса, идёт по тому же пути от корня.
Поэтому достаточно пройти по символам префикса.
Если все переходы нашлись, значит хотя бы один путь с таким началом есть в дереве.

## Как работает

1. Начинаем с корня.
2. Идём по символам префикса.
3. Если очередного перехода нет, возвращаем `false`.
4. Если прошли весь префикс, возвращаем `true`.
5. Флаг `isEnd` здесь не проверяется, потому что префикс не обязан быть словом.

## Пример

Добавим слова `app`, `apple`, `banana`.

```text
root
|- a
|  `- p
|     `- p (конец слова "app")
|        `- l
|           `- e (конец слова "apple")
`- b
   `- a
      `- n
         `- a
            `- n
               `- a (конец слова "banana")
```

Результаты:

```text
StartsWith("app")  -> true  (путь a -> p -> p существует)
StartsWith("appl") -> true  (путь существует, хотя это не слово)
StartsWith("ban")  -> true  (начало слова banana)
StartsWith("band") -> false (пути по букве d нет)
StartsWith("")     -> true  (пустой префикс есть у любого дерева)
```

## Сложность

- Время O(P), где P - длина префикса.
- Дополнительная память O(1).
- Время не зависит от количества слов в дереве.
