# Задача 1. Вставка и поиск слова

## Задача

Реализовать префиксное дерево с двумя операциями:

- `Insert(word)` - добавить слово в дерево;
- `Search(word)` - проверить, есть ли слово в дереве целиком.

`Search` должен возвращать `true`, только если слово было добавлено полностью.
Если в дереве есть только начало слова, например `app`, а ищем `apple`, ответ должен быть `false`.

## Идея

Каждое слово хранится как путь от корня.
Каждое ребро пути подписано одним символом.
Узел хранит два поля:

- `children` - переходы к дочерним узлам по символам;
- `isEnd` - признак того, что путь до этого узла является словом.

## Как работает

### Вставка

1. Начинаем с корня дерева.
2. Идём по символам слова слева направо.
3. Если перехода по символу нет, создаём новый узел.
4. Переходим в дочерний узел.
5. После последнего символа ставим `isEnd = true`.

### Поиск

1. Начинаем с корня дерева.
2. Идём по символам слова слева направо.
3. Если нужного перехода нет, слова в дереве нет.
4. После последнего символа проверяем `isEnd`.
5. Если `isEnd = true`, слово найдено.
6. Если `isEnd = false`, найден только префикс, но не слово.

## Пример

Добавим слова `apple` и `app`.

```text
root
`- a
   `- p
      `- p (конец слова "app")
         `- l
            `- e (конец слова "apple")
```

Результаты поиска:

```text
Search("app")    -> true  (узел p отмечен как конец слова)
Search("apple")  -> true  (узел e отмечен как конец слова)
Search("appl")   -> false (путь есть, но слово не заканчивается)
Search("apples") -> false (пути по букве s нет)
```

## Сложность

- `Insert`: время O(L), память O(L), где L - длина слова.
- `Search`: время O(L), дополнительная память O(1).
- Память на всё дерево: O(суммарной длины всех слов).
