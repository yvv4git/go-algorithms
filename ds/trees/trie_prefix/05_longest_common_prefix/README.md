# Задача 5. Наибольший общий префикс

## Задача

Дан набор слов.
Нужно найти самый длинный префикс, который есть у всех слов набора.

Если общих символов нет, вернуть пустую строку.
Если в наборе одно слово, его наибольший общий префикс - это само слово.
Если набор пуст, вернуть пустую строку.

## Идея

После вставки всех слов в Trie общий префикс - это путь от корня, который проходят все слова.
Пока из текущего узла выходит ровно одно ребро, все слова продолжаются одинаково.
Как только появляется развилка или заканчивается слово, общий префикс заканчивается.

## Как работает

1. Вставляем все слова в префиксное дерево.
2. Начинаем с корня.
3. Проверяем текущий узел:
   - если узел отмечен как конец слова, останавливаемся;
   - если из узла выходит не одно ребро, останавливаемся;
   - иначе переходим по единственному ребру и добавляем символ к ответу.
4. Повторяем шаги, пока можем продолжать путь.
5. Возвращаем накопленную строку.

Остановка на конце слова важна.
Например, для слов `app` и `apple` общий префикс равен `app`, а не `appl`.

## Пример

### Пример 1

```text
Слова: flower, flow, flight
Общий путь: f -> l
Ответ: fl
```

### Пример 2

```text
Слова: app, apple
После слова app стоит отметка конца слова.
Ответ: app
```

### Пример 3

```text
Слова: dog, cat
Из корня выходит два ребра: d и c.
Ответ: пустая строка
```

## Сложность

- Вставка всех слов: O(S), где S - суммарная длина всех слов.
- Поиск общего префикса: O(L), где L - длина ответа.
- Дополнительная память: O(L) для строки ответа.
