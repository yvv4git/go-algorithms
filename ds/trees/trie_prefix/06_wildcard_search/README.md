# Задача 6. Поиск с шаблоном и символом "."

## Задача

Реализовать операцию `SearchWithWildcard(word)`.
Она должна проверять, есть ли в дереве слово, совпадающее с шаблоном.

В шаблоне можно использовать два вида символов:

- обычная буква - должна совпасть с такой же буквой в слове;
- точка `.` - совпадает с любой одной буквой.

Точка не означает "любое количество букв".
Она заменяет ровно один символ.

## Идея

При обычном поиске мы всегда переходим по одному конкретному ребру.
При встрече точки вариантов становится несколько: подходит любой ребёнок текущего узла.
Значит, нужно перебрать всех детей и проверить, приводит ли хотя бы один из них к ответу.

Для этого удобно использовать рекурсию.
Рекурсивная функция получает текущий узел и позицию в шаблоне.

## Как работает

1. Если позиция равна длине шаблона, проверяем `isEnd` текущего узла.
2. Берём очередной символ шаблона.
3. Если это обычная буква, переходим по этому символу.
   Если перехода нет, ветка не подходит.
4. Если это точка, пробуем каждого ребёнка текущего узла.
5. Если хотя бы один ребёнок даёт `true`, возвращаем `true`.
6. Если все варианты перебраны и ни один не подошёл, возвращаем `false`.

## Пример

Добавим слова `bad`, `dad`, `mad`.

```text
SearchWithWildcard("bad") -> true  (точное совпадение)
SearchWithWildcard(".ad") -> true  (подходит bad, dad и mad)
SearchWithWildcard("b..") -> true  (подходит bad)
SearchWithWildcard("b.d") -> true  (подходит bad)
SearchWithWildcard("...") -> true  (любое слово из трёх букв)
SearchWithWildcard("....") -> false (слово из четырёх букв не добавлено)
SearchWithWildcard("pad") -> false (буквы p в дереве нет)
SearchWithWildcard(".")   -> false (слово из одной буквы не добавлено)
```

## Сложность

- В худшем случае время растёт экспоненциально от количества точек.
- Если в шаблоне D точек, может быть до O(26^D) вариантов для латинских букв.
- Точнее, алгоритм посещает некоторое количество узлов дерева, и время равно O(числа посещённых узлов).
- Дополнительная память O(L) на стек рекурсии, где L - длина шаблона.
