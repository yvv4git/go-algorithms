# A. Равенство подстрок

Статус: не решена.

## Ограничения

| Параметр | Значение                           |
|----------|------------------------------------|
| Время    | 15 секунд                          |
| Память   | 512Mb                              |
| Ввод     | стандартный ввод или `input.txt`   |
| Вывод    | стандартный вывод или `output.txt` |

## Условие

Дана строка $S$, состоящая из строчных латинских букв.

Определите, совпадают ли строки одинаковой длины $L$, начинающиеся с позиций $A$ и $B$.

## Формат ввода

- Первая строка содержит строку $S$ ($1 \le |S| \le 2 \cdot 10^5$), состоящую из строчных латинских букв.
- Вторая строка содержит число $Q$ ($1 \le Q \le 2 \cdot 10^5$) — количество запросов.
- Каждый из следующих $Q$ запросов содержит целые числа $L$, $A$ и $B$.
- Ограничения: $1 \le L \le |S|$ и $0 \le A, B \le |S| - L$.
- $L$ — длина подстрок, $A$ и $B$ — позиции, с которых они начинаются.

## Формат вывода

Если строки совпадают — выведите "yes", иначе — "no".

## Примеры

### Пример 1

#### Ввод (пример 1)

```text
acabaca
3
4 3 2
3 4 0
2 0 1
```

#### Вывод (пример 1)

```text
no
yes
no
```
