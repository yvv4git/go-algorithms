# Подходы к задаче "Количество различных подстрок"

## Суть задачи

Дана строка S длины n.
Подстрока S[i..j] - это непрерывный кусок строки с i-го по j-й символ включительно.
Нужно посчитать, сколько различных подстрок встречается в строке.
Всего подстрок с учётом повторов n(n+1)/2, но одинаковые куски считаются один раз.

Пример: S = "abc", различные подстроки: "a", "b", "c", "ab", "bc", "abc", ответ 6.
Пример: S = "aaa", различные подстроки: "a", "aa", "aaa", ответ 3.
Пример: S = "abab", различные подстроки: "a", "b", "ab", "ba", "aba", "bab", "abab", ответ 7.

## Подходы

### 1. Bruteforce (перебор подстрок и хеш-множество)

#### Идея перебора

Перебрать все подстроки и сохранить их отпечатки в множестве.

#### Как работает перебор

Перебираем начало i и конец j подстроки.
Для каждой подстроки считаем полиномиальный хеш за O(1) по префиксным хешам.
Хеш - это числовой отпечаток строки, одинаковые строки дают одинаковый хеш.
Кладём пару хешей с двумя модулями в множество, чтобы уменьшить коллизии.
Количество элементов в множестве и есть ответ.

#### Сложность перебора

Время O(n^2), память O(n^2).

### 2. Suffix trie (суффиксный бор)

#### Идея бора

Сложить все суффиксы строки в дерево, где путь от корня задаёт подстроку.

#### Как работает бор

Бор (trie) - это дерево, в котором каждому символу соответствует ребро.
Вставляем в бор каждый суффикс S[i:] по одному символу.
Каждая различная подстрока - это путь от корня, поэтому она появляется в боре ровно один раз.
Число различных подстрок равно числу вершин бора без корня.

#### Сложность бора

Время O(n^2), память O(n^2).

### 3. Suffix array and LCP (суффиксный массив и LCP)

#### Идея суффиксного массива

Отсортировать все суффиксы и вычесть повторяющиеся начала соседних суффиксов.

#### Как работает суффиксный массив

Суффиксный массив - это номера всех суффиксов строки в лексикографическом порядке.
LCP двух соседних суффиксов - это длина их наибольшего общего префикса.
Всего подстрок с учётом повторов n(n+1)/2.
Каждый общий префикс соседних суффиксов уже был посчитан раньше, поэтому его нужно вычесть.
Ответ равен n(n+1)/2 минус сумма LCP всех соседних пар.

#### Сложность суффиксного массива

Время O(n^2 log n), память O(n).

### 4. Suffix automaton (суффиксный автомат)

#### Идея автомата

Построить автомат, состояния которого хранят группы подстрок с одинаковым набором продолжений.

#### Как работает автомат

Суффиксный автомат - это минимальный автомат, принимающий все подстроки строки.
У каждого состояния v есть длина len[v] и суффиксная ссылка link[v] на состояние с более короткими строками.
Состояние v отвечает за len[v] - len[link[v]] различных подстрок.
Сумма этих величин по всем состояниям, кроме начального, и есть ответ.

#### Сложность автомата

Время O(n), память O(n).

## Сравнение подходов

| Подход             | Время           | Память   | Сложность кода |
|--------------------|-----------------|----------|----------------|
| Перебор подстрок   | $O(n^2)$        | $O(n^2)$ | Низкая         |
| Суффиксный бор     | $O(n^2)$        | $O(n^2)$ | Средняя        |
| Суффиксный массив  | $O(n^2 \log n)$ | $O(n)$   | Высокая        |
| Суффиксный автомат | $O(n)$          | $O(n)$   | Высокая        |

## Что выбрать

- При n <= 1024 подойдёт даже перебор подстрок с хеш-множеством.
- Суффиксный бор проще для понимания, но занимает O(n^2) памяти.
- Суффиксный массив и автомат дают O(n) памяти и надёжно работают на больших строках.
- Самый быстрый вариант - суффиксный автомат за O(n) времени.
