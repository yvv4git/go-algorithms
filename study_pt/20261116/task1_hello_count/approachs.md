# Подходы к задаче "Hello Counter"

## Суть задачи

В опенспейсе работают a интровертов и b экстравертов.
Каждый день они заходят по одному в случайном порядке.
Интроверт при входе отвечает на приветство уже находящихся экстравертов.
Экстраверт при входе здоровается со всеми, кто уже внутри, и все ему отвечают.
Надо посчитать, сколько раз за день произнесено слово "Hello!".
Ответ не зависит от порядка входа, поэтому его можно вычислить одной формулой.

## Подходы

### 1. Formula

#### Идея formula

Посчитать ответ по парам сотрудников, а не по шагам входа.
Каждая пара сотрудников, между которыми возможен привет, обменивается двумя словами "Hello!" ровно один раз за день.

#### Как работает formula

Интроверт - это сотрудник, который сам не здоровается первым.
Экстраверт - это сотрудник, который здоровается со всеми, кто уже внутри.
Слово "Hello!" всегда произносится парами: один говорит, второй отвечает.
Поэтому достаточно найти число подходящих пар и умножить его на 2.

Разберём три вида пар на примере a = 1 интроверт и b = 2 экстраверта.

```text
Сотрудники: I1 (интроверт), E1, E2 (экстраверты)

Пара I1 и E1: когда второй входит, первый внутри -> 2 привета
Пара I1 и E2: когда второй входит, первый внутри -> 2 привета
Пара E1 и E2: когда второй входит, первый внутри -> 2 привета
Пара I1 и I1: один сотрудник, пары нет
Итого: 2 + 2 + 2 = 6
```

Теперь посчитаем число пар в общем виде.

- Пар "интроверт и экстраверт" ровно a*b, потому что каждого интроверта можно соединить с каждым экстравертом.
- Пар "два экстраверта" ровно b*(b-1)/2, это число сочетаний из b по 2.
- Пар "два интроверта" нет, интроверты не начинают разговор.

Каждая такая пара даёт ровно 2 привета, значит ответ равен 2*a*b + b*(b-1).

Порядок входа не меняет счёт: пара встречается в опенспейсе в момент входа второго участника, а это происходит ровно один раз за день.

Проверим формулу на обоих примерах задачи.

```text
a = 1, b = 2: 2*1*2 + 2*(2-1) = 4 + 2 = 6
a = 5, b = 0: 2*5*0 + 0*(0-1) = 0 + 0 = 0
a = 0, b = 2: 2*0*2 + 2*(2-1) = 0 + 2 = 2
a = 0, b = 0: 2*0*0 + 0*(0-1) = 0
```

#### Сложность formula

Формула выполняется за O(1) времени, потому что содержит только несколько арифметических операций.
Дополнительная память не нужна, сложность O(1).
При a = b = 10^9 ответ равен 3*10^18 - 10^9, что помещается в 64-битное знаковое число.

## Сравнение подходов

| Подход  | Время | Память | Коллизии | Сложность кода |
|---------|-------|--------|----------|----------------|
| Formula | O(1)  | O(1)   | нет      | низкая         |

## Что выбрать

- Всегда выбирайте formula: ответ не зависит от порядка входа и считается одной формулой.
- Перебор порядка входа не нужен: он дал бы тот же ответ, но за O(a+b) или больше.
- Следите за типом данных: ответ до ~3*10^18, поэтому считайте в int64.
