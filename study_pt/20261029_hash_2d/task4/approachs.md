# Подходы к задаче "Hack the Polynomial Hash"

## Суть задачи

Нужно вывести N различных строк из строчных латинских букв.
Для каждой строки считается полиномиальный хеш по модулю 128 с одним и тем же основанием x из диапазона 2..127.
Требуется, чтобы у всех выведенных строк хеш был одинаковым, причём x нам не сообщают.
Длина каждой строки не должна превышать 5000 символов.
Например, при N = 1 подойдёт любая строка, а при N = 128 нужно построить целое семейство строк-коллизий.

## Подходы

### 1. Thue-Morse blocks

#### Идея Thue-Morse blocks

Сделать так, чтобы разность хешей любых двух строк обращалась в ноль по модулю 128 при любом x.

#### Как работает Thue-Morse blocks

Хеш строки - это значение многочлена от x, где коэффициенты равны ASCII-кодам символов, по модулю 128.
Модуль 128 равен 2^7, поэтому для чётного x слагаемые со степенью 7 и выше исчезают, и хеш зависит только от последних 7 символов.
Все строки заканчиваются одинаковым суффиксом `aaaaaaa`, поэтому для чётных x их хеши равны.
Для нечётного x используется последовательность Туэ-Морса: t[i] равно чётности числа единиц в двоичной записи i.
Строится блок A длины 64: на позиции i стоит `a`, если t[i] = 0, и `b` иначе.
Блок B строится как дополнение: на позиции i стоит `b`, если t[i] = 0, и `a` иначе.
Разность многочленов блоков A и B равна (1-x)(1-x^2)(1-x^4)(1-x^8)(1-x^16)(1-x^32) с точностью до знака.
Для нечётного x выполнено x^32 = 1 (mod 128), поэтому последний множитель равен нулю и разность блоков равна нулю.
Строка собирается из 7 блоков: для каждого бита номера строки выбирается блок A или блок B.
После блоков добавляется общий суффикс длины 7.
Все строки имеют одинаковую длину 7*64+7 = 455, поэтому блоки выровнены по степеням x.
Разность хешей любых двух строк является суммой разностей блоков, умноженных на степени x, и равна нулю для всех x из 2..127.
Разные номера строк дают разные комбинации блоков, поэтому все 128 строк попарно различны.

#### Сложность Thue-Morse blocks

Каждая строка имеет фиксированную длину 455 символов.
Для N строк время равно O(N*455), память - O(N*455).
При N <= 128 это меньше 60000 символов.

## Сравнение подходов

| Подход             | Время      | Память     | Коллизии              | Сложность кода |
|--------------------|------------|------------|-----------------------|----------------|
| Thue-Morse blocks  | O(N*455)   | O(N*455)   | гарантированы mod 128 | средняя        |

## Что выбрать

- Для этой задачи достаточно одного подхода Thue-Morse blocks.
- Конструкция работает для всех x от 2 до 127, поэтому угадывать x не нужно.
- Строки имеют длину 455, что с большим запасом меньше ограничения 5000.
