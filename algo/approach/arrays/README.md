# Arrays

Линейные техники обхода и обработки массивов за один проход или с предвычислением.

- **two_pointers** — два указателя, сходящихся или идущих в одном направлении.
- **sliding_window** — окно фиксированной или динамической ширины.
- **prefix_sum** — префиксные суммы для быстрых запросов на отрезке.
- **counting** — подсчёт частот элементов.
- **bucket_sort** — распределение элементов по корзинам.
