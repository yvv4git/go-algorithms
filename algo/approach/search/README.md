# Search

Подходы к поиску элемента, выборке и поиску подстроки.

- **binary_search** — поиск по отсортированному массиву за O(log n).
- **median_of_medians** — выбор медианы за линейное время.
- **kmp** — поиск подстроки через префикс-функцию.
- **prefix_search** — семейство строковых алгоритмов: aho_corasick, rabin_karp, boyer_moore, z_function.
- Внутри prefix_search также: suffix_array, suffix_tree, bor_trie, bitap, automaton, prefix_func, naive.
