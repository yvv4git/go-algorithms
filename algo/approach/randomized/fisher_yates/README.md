# Fisher-Yates Shuffle

Алгоритм тасования Фишера-Йетса перемешивает массив так, что любая из n! перестановок встречается с равной вероятностью.

## Описание

Алгоритм идёт по массиву с конца и на каждом шаге меняет текущий элемент со случайным из оставшейся части.
Случайный индекс j выбирается равномерно из диапазона от 0 до i, где i — текущая позиция.
Вероятность каждой из n! перестановок равна 1/n!, поэтому перемешивание не имеет смещений.
Алгоритм также известен под названием Knuth shuffle.

## Сложность

| Свойство | Значение |
| -------- | -------- |
| Время    | O(n)     |
| Память   | O(1)     |

Перемешивание выполняется на месте и состоит ровно из n-1 обменов.
