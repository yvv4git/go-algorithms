# Paradigms

Общие стратегии, по которым строится решение задачи.

- **bruteforce** — перебор всех вариантов.
- **backtracking** — поиск с откатом при тупике.
- **greedy** — локально оптимальный выбор на каждом шаге.
- **dynamic_programming** — сохранение подрешений для переиспользования.
- **divide_and_conquer** — разбиение задачи на подзадачи и слияние ответов.
- **recursion** — решение через рекурсивные вызовы.
- **backward** — движение от цели к исходным данным.
