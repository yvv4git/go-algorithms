# Data Structures

Структуры данных как инструмент для построения алгоритмов.

- **heap** — кучи: двоичная, биномиальная, фибоночева, k-ary, treap, приоритетная очередь.
- **fenwick_tree** — дерево Фенвика для сумм на отрезке и обновлений за O(log n).
- **stack** — стек: DFS, валидация скобок, варианты сортировок.
- **queue** — очередь (заглушка).
- **hash_table**, **hashmap**, **hashset** — хеш-таблицы (заглушки).
