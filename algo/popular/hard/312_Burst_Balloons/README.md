# 312. Burst Balloons

## Info

Задача 312. Burst Balloons - классическая задача на динамическое программирование (interval DP).
Дан массив nums, шары лопаются по одному; при лопании i-го шара получаем `nums[i-1] * nums[i] * nums[i+1]` очков,
а за границами массива считаются единицы. Нужно найти максимальное суммарное количество очков.
Решается за O(n^3) перебором последнего лопнутого шара на каждом подотрезке.

## Level - hard

## Task

You are given n balloons, indexed from 0 to n - 1. Each balloon is painted with a number on it represented by an array nums. You are asked to burst all the balloons.

If you burst the ith balloon, you will get `nums[i - 1] * nums[i] * nums[i + 1]` coins. If i - 1 or i + 1 goes out of bounds of the array, then treat it as if there is a balloon with a 1 painted on it.

Return the maximum coins you can collect by bursting the balloons wisely.

## Объяснение

Нужно лопать шары по одному, пока массив не станет пустым. За лопание i-го шара
начисляются очки, равные произведению трёх соседних значений: число на самом шаре
и числа на соседних слева и справа. Если соседа нет (шар на краю), вместо него
берётся единица. Порядок лопания влияет на результат, поэтому требуется найти
порядок, который даёт максимальную сумму очков.

Прямой перебор всех порядков лопания - это n! вариантов, что для n = 300 нереально.
Поэтому задача решается перебором в обратном порядке и динамическим программированием.

Подходы:

- Полный перебор - перебирать все перестановки порядка лопания и считать очки.
  Сложность O(n!), работает только для маленьких n.
- Разделяй и властвуй - рассмотреть лопание шаров в обратном порядке: последний
  лопнувший шар на отрезке считается "последним" и его соседями становятся границы
  отрезка. Сложность O(n^3) с мемоизацией.
- Динамическое программирование (interval DP) - решать подзадачу для каждого
  подотрезка `dp[i][j]`: максимальные очки, которые можно получить, лопая все шары
  между i и j включительно. Перебирать, какой шар лопнуть последним, и комбинировать
  результаты левого и правого подотрезков. Сложность O(n^3) по времени и O(n^2)
  по памяти.

## Example 1

```text
Input: nums = [3,1,5,8]
Output: 167
Explanation:
nums = [3,1,5,8] --> [3,5,8] --> [3,8] --> [8] --> []
coins =  3*1*5    +   3*5*8   +  1*3*8  + 1*8*1 = 167
```

## Example 2

```text
Input: nums = [1,5]
Output: 10
```

## Constraints

- n == nums.length
- 1 \<= n \<= 300
- 0 \<= nums[i] \<= 100
