# 2261. K Divisible Elements Subarrays

## Info

Нужно посчитать количество различных подмассивов, в которых не более `k` элементов делятся на `p`.
Ключевая идея: перебрать все подмассивы, отбросить те, где число делящихся элементов больше `k`, и сохранить подходящие в множество без повторов.
Итоговая сложность O(n^2) по времени и O(n^2) по памяти при использовании префиксного дерева.

## Level - medium

## Task

Given an integer array nums and two integers k and p, return the number of distinct subarrays with at most k elements divisible by p.
Two arrays nums1 and nums2 are said to be distinct if:

- They are of different lengths, or
- There exists at least one index i where nums1[i] != nums2[i].

A subarray is defined as a non-empty contiguous sequence of elements in an array.

## Объяснение

Подмассив - это непрерывная часть массива, заданная границами `left` и `right`.
Два подмассива различны, если у них разная длина или хотя бы один элемент на одинаковой позиции отличается.
Нужно найти количество различных подмассивов, в которых количество элементов, делящихся на `p`, не превышает `k`.

Перебираем все возможные левые границы `left`.
Для каждой левой границы двигаем правую границу `right` вправо и поддерживаем счётчик `divisible` элементов, делящихся на `p`.
Если `divisible` превышает `k`, дальнейшие подмассивы с этой левой границей не подходят, поэтому перебор для неё прекращается.
Каждый подходящий подмассив сохраняется в множество, чтобы одинаковые подмассивы не считались дважды.

Разберём пример `nums = [2, 3, 3, 2, 2]`, `k = 2`, `p = 2`.
На 2 делятся числа на позициях 0, 3 и 4.
Выпишем все различные подходящие подмассивы по длинам:

- длина 1: `[2]`, `[3]`;
- длина 2: `[2, 3]`, `[3, 3]`, `[3, 2]`, `[2, 2]`;
- длина 3: `[2, 3, 3]`, `[3, 3, 2]`, `[3, 2, 2]`;
- длина 4: `[2, 3, 3, 2]`, `[3, 3, 2, 2]`;
- длина 5: `[2, 3, 3, 2, 2]` не подходит, в нём три элемента делятся на 2.

Считаем: `2 + 4 + 3 + 2 = 11` различных подмассивов.
Всего в массиве 15 подмассивов, полный `[2, 3, 3, 2, 2]` не подходит, поэтому подходящих вхождений 14.
Но `[2]` встречается три раза, а `[3]` два раза, поэтому различных подмассивов `14 - 2 - 1 = 11`.

Подходы:

- Bruteforce (перебор с хеш-таблицей). Подходящие подмассивы складываются в множество строк; время O(n^3), память O(n^3).
- Trie (префиксное дерево). Новые вершины дерева дают число различных подмассивов; время O(n^2), память O(n^2).

Для ограничения `n <= 200` подходит и перебор, но префиксное дерево быстрее и не копирует подмассивы целиком.

## Example 1

```text
Input:
5 2 2
2 3 3 2 2

Output:
11
```

Explanation: the suitable distinct subarrays are [2], [2,3], [2,3,3], [2,3,3,2], [3], [3,3], [3,3,2], [3,3,2,2], [3,2], [3,2,2] and [2,2].

## Example 2

```text
Input:
4 4 1
1 2 3 4

Output:
10
```

Explanation: every element is divisible by 1, all subarrays satisfy the limit, and all 10 subarrays are distinct.

## Constraints

- 1 <= nums.length <= 200
- 1 <= nums[i], p <= 200
- 1 <= k <= nums.length
- Input: the first line contains `n`, `k` and `p`, the second line contains `n` integers
- Output: the number of distinct suitable subarrays
