# 718. Maximum Length of Repeated Subarray

## Info

Задача 718. Maximum Length of Repeated Subarray - найти длину наибольшего общего подмассива двух массивов.
Ключевая идея - динамика `dp[i][j]` по длине общего суффикса.
Итоговая сложность: O(n*m) по времени и O(min(n,m)) по памяти.

## Level - medium

## Task

Given two integer arrays nums1 and nums2, return the maximum length of a subarray that appears in both arrays.

## Объяснение

Нужно найти максимальную длину непрерывного отрезка, который встречается в обоих массивах.
Подмассив обязан быть непрерывным, поэтому нельзя просто взять общие элементы в произвольном порядке.
Основная идея - динамическое программирование по парам индексов.

Подходы:

- Bruteforce (полный перебор). Для каждой пары индексов сравнивать элементы до несовпадения.
  Время O(n*m*min(n,m)), память O(1).
- Dynamic programming (динамическое программирование). В `dp[i][j]` хранить длину общего подмассива.
  Он заканчивается в позициях i и j, а таблица имеет размер (n+1) x (m+1).
  При равенстве nums1[i-1] и nums2[j-1] значение растёт на единицу, иначе сбрасывается в ноль.
  Время O(n*m), память O(n*m), но её можно сократить до O(min(n,m)).

Переход в динамике:

```text
if nums1[i-1] == nums2[j-1]:
    dp[i][j] = dp[i-1][j-1] + 1
else:
    dp[i][j] = 0
```

Почему это работает: при совпадении последних элементов общий подмассив можно продлить на один элемент.
При различии элементов общего подмассива с таким концом не существует.
Поэтому `dp[i][j]` либо продолжает диагональ `dp[i-1][j-1]`, либо равно нулю.
Нулевая строка и нулевой столбец убирают отдельные проверки выхода за границы.
Ответ - максимум по всей таблице, а не только в последней ячейке.
Память можно сократить до O(min(n,m)): при переходе нужна только предыдущая строка таблицы.
Итоговая сложность: O(n*m) по времени и O(min(n,m)) по памяти.

## Example 1

```text
Input: nums1 = [1,2,3,2,1], nums2 = [3,2,1,4,7]
Output: 3
Explanation: The repeated subarray with maximum length is [3,2,1].
```

## Example 2

```text
Input: nums1 = [0,0,0,0,0], nums2 = [0,0,0,0,0]
Output: 5
Explanation: The repeated subarray with maximum length is [0,0,0,0,0].
```

## Constraints

- 1 <= nums1.length, nums2.length <= 1000
- 0 <= nums1[i], nums2[i] <= 100
