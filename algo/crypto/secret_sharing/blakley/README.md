# Blakley Secret Sharing

## Info

Blakley (1979) - один из двух оригинальных методов разделения секрета, наряду с Shamir.
Секрет представляется как точка в m-мерном пространстве, а каждая доля - гиперплоскость через эту точку.
Для восстановления нужно собрать m гиперплоскостей.
Их пересечение даёт точку, первая координата которой - секрет.

## Что это?

Секрет `S` - первая координата точки в поле:

```text
T = (S, a_1, a_2, ..., a_{m-1}), где a_i - случайные координаты точки
```

Доля `i` - гиперплоскость, проходящая через эту точку:

```text
share_i = (b_{i1}, b_{i2}, ..., b_{i,m-1}, y_i)

  y_i = b_{i1}·a_1 + b_{i2}·a_2 + ... + b_{i,m-1}·a_{m-1} + S
```

Всего N долей, для восстановления нужно m.

## Восстановление

Решается система из m линейных уравнений по отношению к неизвестным `x_0 = S`, `x_1 ... x_{m-1}`:

```text
y_1 = x_0 + b_11·x_1 + ... + b_1,m-1·x_{m-1}
y_2 = x_0 + b_21·x_1 + ... + b_2,m-1·x_{m-1}
...
y_m = x_0 + b_m1·x_1 + ... + b_m,m-1·x_{m-1}
```

Решение - метод Гаусса по модулю простого числа, секретом считается `x_0`.

## Пример

Секрет `S = 13`, поле `mod 257`, порог 2, точка `T = (13, 145)`:

```text
share_1: y = x0 + 229·x1 = 65
share_2: y = x0 + 149·x1 = 30
share_3: y = x0 + 29·x1  = 106
```

Две любые плоскости дают систему 2x2, решение которой `x0 = 13`.
Одна плоскость оставляет прямую, и секрет на ней не определён.

## Blakley против Shamir

- **Blakley** - геометрия: точка и гиперплоскости, восстановление через решение СЛАУ `O(m³)`
- **Shamir** - полином: секрет и коэффициенты, восстановление через интерполяцию Лагранжа `O(m²)`
- Доля Blakley хранит `m` чисел вместо одного, поэтому она крупнее доли Shamir
- На практике предпочитают Shamir, Blakley остаётся в теории и в протоколах DKG

## Ограничения

- Все числа должны быть в конечном поле, иначе накапливается погрешность
- Решение СЛАУ дороже интерполяции и чувствительно к вырожденным системам
- Классическая версия не позволяет добавить долю без пересчёта остальных

## Где применяется

- Исторически - один из первых методов разделения секрета
- Теоретическая основа для Blakley-RSS, рационального разделения секрета
- Совместно с Shamir - в протоколах совместной генерации ключа
