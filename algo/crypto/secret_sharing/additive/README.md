# Additive Secret Sharing

## Info

Additive Secret Sharing - простейший метод разделения секрета.
Секрет разбивается на доли, сумма которых даёт оригинал.
Минимальная версия работает как M = N, то есть нужны все доли.
Порог получается через композицию с Shamir.

## Что это?

Дилер выбирает N-1 случайных долей, а последнюю считает так, чтобы сумма давала секрет:

```text
share_1 = random(p)
...
share_{N-1} = random(p)
share_N = S - Σ_{i=1..N-1} share_i (mod p)
```

Восстановление - одно сложение:

```text
S = Σ share_i (mod p)
```

Доли не привязаны к точкам и не имеют координат, это отличает схему от полиномиальных.

## Свойства

- **Perfect secrecy** - N-1 долей не дают никакой информации о секрете
- **Линейность** - гомоморфизм по сложению: `share(a) + share(b) = share(a + b)`
- **Минимальный размер** - каждая доля того же размера, что и секрет
- **Только N-из-N** - без расширения не поддерживает threshold

## Пример

Секрет `S = 13`, поле `mod 257`, три доли:

```text
share_1 = 197
share_2 = 71
share_3 = 13 - (197 + 71) mod 257 = 2

197 + 71 + 2 = 270 mod 257 = 13
```

Сумма двух долей `197 + 71 = 11` секретом не является, но и ничего не выдаёт.
`share_3` остаётся равновероятной.

## Где применяется

- **MPC** - протоколы GMW, BGW, SPDZ, MASCOT
- **Приватная обработка данных** - голосование, аукционы
- **Совместное хранение ключей** - когда нужно участие всех сторон

## Ограничения

- Без Shamir схема даёт только N-из-N: любые M < N долей не восстановят секрет
- Неполная сумма неотличима от любой другой, состав участников менять нельзя
- Пересчёт долей требует участия всех сторон сразу
